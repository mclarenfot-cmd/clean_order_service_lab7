# Clean Order Service

Мини-сервис управления заказами для лабораторной работы 7.

Проект построен по принципам Чистой архитектуры:

- `src/domain` - бизнес-сущности и правила расчета заказа;
- `src/use_cases` - сценарии использования и абстрактные интерфейсы;
- `src/infrastructure` - конкретные реализации внешних механизмов;
- `main.py` - корень композиции, где связываются зависимости.

Запуск демонстрации:

```bash
python3 main.py
```

Запуск тестов:

```bash
python3 -m unittest discover -s tests
```
